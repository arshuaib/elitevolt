EliteVolt Systems — Meta Commerce / Pixel setup

PRODUCT FEED
Ready-to-upload CSV file: facebook-product-feed.csv
Scheduled feed URL: https://elitevoltsystems.com/facebook-product-feed.csv
RSS/XML alternative: https://elitevoltsystems.com/merchant-feed.xml

Both feeds are generated from the product catalog in js/shop.js. The CSV
contains IDs, titles, descriptions, current stock, regular and sale prices,
product and image URLs, brand and category. Run
`node scripts/generate-facebook-feed.mjs` after changing products. The
GitHub Pages deployment workflow runs this automatically before publishing,
so the scheduled feed URL is refreshed with each site deployment.

In Meta Commerce Manager, upload facebook-product-feed.csv directly, or add
the scheduled CSV URL above as a data feed source. The XML URL remains
available for existing integrations.

META PIXEL
Every page on the site (home, shop, all 14 product pages, all blog and
service pages) now includes js/meta-pixel.js and a
<meta name="meta-pixel-id" content=""> tag in its <head>. To activate the
pixel sitewide, put your numeric Meta Pixel ID into that one meta tag on
EVERY page (find/replace across the project is the fastest way):

<meta name="meta-pixel-id" content="YOUR_NUMERIC_PIXEL_ID">

Do not include quotes or spaces inside the numeric ID.

Once the ID is set, the site automatically sends:
- PageView on every page load
- ViewContent on each product page (id, name, price)
- AddToCart when a shopper adds an item from the shop grid or a product
  page (content_ids, content_name, value, currency GHS, contents)
- InitiateCheckout when a shopper taps "WhatsApp Order" or "Email Order"
  in the cart (value = cart total, num_items, contents)
- Lead when a shopper requests a quote from the home page solar
  calculator, by WhatsApp or email

The AddToCart hook also emits a browser event you can hook into for your
own analytics: elitevolt:addtocart (similarly elitevolt:initiatecheckout).

The catalog filter/search/wishlist system is fully client-side and does
not reload the page. Cart and wishlist data live in the shopper's own
browser (localStorage) — there is no shared/server-side cart.
