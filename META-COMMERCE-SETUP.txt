EliteVolt Systems — Meta Commerce / Pixel setup

PRODUCT FEED
Ready-to-upload CSV file: facebook-product-feed.csv
Scheduled feed URL: https://elitevoltsystems.com/facebook-product-feed.csv
RSS/XML alternative: https://elitevoltsystems.com/merchant-feed.xml

Both feeds are generated from the product catalog in js/shop.js. The CSV
contains IDs, titles, descriptions, current stock, regular and sale prices,
product and image URLs, brand and category. The GitHub Pages workflow runs
the catalog updater and feed generator before every deployment. It creates a
product page when a catalog item has a new pageUrl, refreshes sitemap.xml,
then generates both catalog feeds from the same product data.

To add an item, add a complete product record to productsData in js/shop.js,
including a unique id and pageUrl under products/. Commit and push to main.
The next Pages deployment publishes the new product page, shop listing,
sitemap entry, CSV feed and XML feed together. For a local preview, run:

`node scripts/update-catalog.mjs`
`node scripts/generate-facebook-feed.mjs`

The blog index and eight long-form guides are generated from
scripts/generate-blog-guides.mjs. Edit that source file to update the guide
content; the deployment workflow rebuilds the blog index and article pages.

In Meta Commerce Manager, upload facebook-product-feed.csv directly, or add
the scheduled CSV URL above as a data feed source. The XML URL remains
available for existing integrations.

META PIXEL
The sitewide Meta Pixel ID is centrally configured in js/meta-pixel.js:
1115706364423032. Every published page loads this shared script, including
product and blog pages created by the site generators. Keep the ID in that
single configuration point when it needs to change.

The site automatically sends:
- PageView on every page load
- ViewContent on each product page (catalog ID, name, category, and current price)
- Search when a shopper submits a product search; email addresses and phone-like
  searches are omitted from event data
- AddToWishlist when a shopper saves a product
- AddToCart when a shopper adds an item from the shop grid or a product
  page (catalog IDs, quantity, item price, category, and cart value in GHS)
- InitiateCheckout when a shopper taps "WhatsApp Order" or "Email Order"
  in the cart (cart value in GHS, item IDs, quantities, and item prices)
- Contact when a shopper taps a WhatsApp, email, or phone link; message text
  and contact details are not sent
- Lead when a shopper requests a quote from the solar calculator by WhatsApp
  or email (estimated system size is sent without a monetary value)

There is no Purchase event because checkout and payment happen outside the
website and there is no confirmed purchase page to report.

After deployment, use Meta Events Manager's Test Events view and the Meta
Pixel Helper browser extension to confirm each event and its parameters.
NOTES
- Product IDs match the IDs used in the pixel events and the
  "sku" field in each product page's Product structured data, so Meta's
  dynamic ads / catalog matching will line up when the catalog uses either
  generated feed file.
- Two catalog images are currently placeholders and should be replaced
  with real product photos before running catalog/dynamic ads: the Ritar
  12V 200Ah battery's main and thumbnail images, and the SRNE 6kW HV
  inverter's second thumbnail (see recommendations from EliteVolt's last
  review for details).
